# Alexander Hardinan

Official website of **Alexander Hardinan** — Executive Chef & Culinary Innovator.

This site showcases modern gastronomy, personal branding, projects, and professional presence, built with a high-performance, animated UI and Progressive Web App (PWA) support.

---

## Tech Stack
- **Next.js 14 (App Router)**
- **React 18**
- **TypeScript**
- **Firebase**
- **Swiper**
- **PWA (Manifest + Installable)**
- **Vercel (deployment only, no branding)**

---

## Features
- Modern responsive UI/UX
- Progressive Web App (installable on mobile & desktop)
- Custom branding and icons
- Contact widget
- Buy Me a Coffee widget with live attention animation
- SEO + OpenGraph + structured data
- Optimized assets and caching
